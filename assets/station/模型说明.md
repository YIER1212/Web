# 空间站主体模型

- `orbital_station.blend`：Blender 可编辑源文件，保留独立部件、材质、灯光与展示相机。
- `station_preview.png`：Blender 渲染预览。
- `../../public/models/orbital_station.glb`：网页用模型，按材质和舱段合并为 23 个网格批次。
- `model_stats.json`：最新导出的面数与文件大小。
- 本地旋转预览：`http://127.0.0.1:3000/station-model`。

模型已接入本地首页。环位于 XY 平面，轴向为 Z，GLB 导出关闭坐标轴转换。四个舱段中心距轴线 28，舱口位于 Z=19.65。入口路由记录在 `port_*` 空对象与网格的 `port_id` 自定义属性中。

首页采用 `createBlenderStation.js` 加载 GLB，并在四个实体舱段内安装内容屏幕和陈设。`stationFlight.js` 提供相机入口与停靠坐标。`scripts/check_station_model.mjs` 对实际导出网格检查所有进出和舱间路线；独立模型页仍用于观察、旋转和缩放。

重新生成：在项目根目录运行 `D:\App\Blender\blender.exe --background --factory-startup --python scripts/build_station_blender.py`。脚本在单独的后台 Blender 进程中运行，并覆盖本目录生成成果及网页 GLB。
