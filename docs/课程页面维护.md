# 课程页面

页面地址：`/courses`。课程记录保存在 `data/courses.json`，每门课填写一条记录：

```json
{
  "id": "unique-course-id",
  "title": "课程中文名称",
  "titleEn": "English course title",
  "category": "人工智能",
  "summary": "一句话介绍学习内容或自己的收获。",
  "url": "https://example.com/course",
  "cover": "/images/courses/waves.svg"
}
```

`url` 支持 HTTP(S) 外部课程页和以单个 `/` 开头的站内笔记地址。外部链接在新标签页打开。`id` 不重复。分类按钮由记录自动生成，中英文名称、分类和简介均可搜索。

自有封面放入 `public/images/courses/`，建议横向约 720 × 260，填写去掉 `public` 的路径。未填写封面或图片加载失败时使用统一的波形插画。

尚未填入真实课程时，开发模式显示 `data/course-examples.json` 中的六张示例卡片，页面上有“视觉预览”标识，示例不提供虚构的课程链接。生产构建仅使用 `data/courses.json`，不会把示例作为已学习记录发布。
